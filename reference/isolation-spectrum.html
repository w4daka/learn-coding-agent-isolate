隔離早見表 — 手段×効果

印刷用チートシート。詳細の正本は RESOURCES.md の一次資料。

手段何を閉じるか特権向く場面
専用ユーザー＋パーミッションUID 境界。読めない・書けないを EACCES で観測作成時のみ sudo（人間）まず最初の一枚。コスト最小
ACL（setfacl）特定パスのみ例外的に見せる不要（所有者操作）workspace だけ見せたい時
bwrap（bubblewrap）mount・pid・net 名前空間。見せない物は ENOENT、書かせない物は EROFS不要（user ns）軽量・起動一発の隔離実行
systemd sandbox（ProtectSystem 等）unit 単位の FS・権限・syscall 制限system scope は要 sudo、user scope は不要常駐サービス化する時
Docker / containerFS・net・cgroup・capability を束で制限docker グループ（実質 root 相当。要注意）再現環境・使い捨て実行
MicroVM（Docker Sandboxes 等）VM 境界。カーネル脱出への耐性要セットアップ信用ゼロのコードを走らせる時
観測の物差し: EACCES＝権限不足で拒否、EROFS＝読取専用で拒否、ENOENT＝見えていない（隔離成功の匂い）。exit code と stderr を必ず残せ。
